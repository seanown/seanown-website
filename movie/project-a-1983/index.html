A計劃

Project A · 1983
A計劃
Project A · 1983
導演 成龍 ｜ 原著·編劇 成龍

《A計劃》是成龍自導自演的動作喜劇，講述水師巡捕馬如龍（成龍）與海盜鬥智鬥力的故事。片中一段澳門戲在氹仔舊城與路環取景，馬如龍抱著華女從斜坡奔逃、跳下教堂台階的幾分鐘，成為這部香港電影留在澳門最珍貴的影像。

跟著電影重走《A計劃》
全片澳門戲集中在氹仔舊城與路環兩處，彼此相鄰、步行可達。下列座標經網查（OpenStreetMap、Wikimedia、Wikipedia）核對確認，可直接對應片中機位。
一、主場景（核心打卡）
光復街（氹仔舊城區）
📍 22.1540, 113.5596

全片澳門戲的第一現場。馬如龍與華女跳牆落地後，被追到這裡，往斜坡下方跑，背景就是嘉模聖母堂的黃色外牆。重現方式：站在光復街靠教堂的最高處，面朝下坡的方向，往下跑——你跑的這段路就是片中那條。坡度不陡，但片中之後接的是爬牆戲，跑完別急著停。

📷 機位建議：在光復街靠嘉模聖母堂的最高處，鏡頭朝下坡方向跟拍奔跑的人，把黃牆與斜坡同時收進畫面。

嘉模聖母堂與嘉模前地
📍 22.1535, 113.5588

片中背景那棟黃色建築。教堂北側有一處不規則的台階，馬如龍抱著華女從那裡跳下來。教堂前平地上立著的十字架，四十多年後仍然在原位，是最好認的定位標記。拍照建議：從光復街下坡的方向回頭看教堂，可以一次把黃牆與斜坡收進同一個畫面。（前地座標 22.1537, 113.5589）

📷 機位建議：從光復街下坡方向回頭拍教堂，把黃牆、前地十字架與斜坡收進同一畫面；北側不規則台階可還原跳落機位。

路環聖方濟各聖堂
📍 22.1169, 113.5515

馬如龍背著假人從小巷衝出來、把戚幫辦撞倒那一場的地點。辨識點在教堂南側門，以及門前那三節台階——當年就是靠這兩個特徵被認出來的。教堂外牆的白石磚形狀也是線索。站在這裡的時候請記得，你面前就是整場戲的取景教堂，而你腳下三步就是片中那道階。

📷 機位建議：在教堂南側門與三節台階前，低角度還原「由巷衝出撞人」的動線；白石磚外牆作背景。

陳勝記（計單奴街）
📍 22.1168, 113.5513

就在聖方濟各聖堂旁邊。做陳皮鴨出名，曾上過《舌尖上的中國》，有七十多年歷史。片中可以清楚看見它當年的大排檔門面。現在想吃要排隊——這是本篇唯一一個「排隊」就能重現電影場景的地方。

📷 機位建議：在計單奴街陳勝記門前平拍大排檔門面，把聖堂廣場收作遠景背景。

二、小眾隱藏場景
十月初五馬路（路環）
📍 22.1151, 113.5504

聖方濟各聖堂與陳勝記門前那一條路。路名紀念葡萄牙一九一〇年十月五日革命，是一條有政治身世的海濱馬路。建議走法：從十月初五馬路的起點沿海慢走到聖堂前，這條路本身就是澳門最完整的一段舊漁村風景，片中鏡頭只帶到了其中兩秒。

📷 機位建議：從馬路起點沿海慢移，把舊漁村海濱與聖堂前地串成一段，重現片中兩秒帶過的質地。

找一天去氹仔，站在光復街最高處，往下跑。跑到底停下來回頭——那面黃色的牆，四十年來沒有變過位置。它只是在等有人跑下來而已。
