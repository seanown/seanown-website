# STORY.md — 高效會議主持 SOP（附屬文章演講稿）

## ① 用戶意圖對齊

**目標受眾**：協會理監事會、會員大會、專題論壇、座談會、跨單位協調會的組織者與主持人；這份 PPT 是 seanown.org 文章《會議結束了，事情才開始》的**附件**，同時可作為內訓與現場投影的講稿。

**核心目標**：講完後觀眾記住三件事——① 主持人不是最會講的人，是讓會議產生結果的人；② 開場快、內容穩、轉場快、高潮慢、結尾快而有力；③ 散會前必須把「誰、做什麼、何時完成」白紙黑字定下來。並立刻能用於下一場會議。

**PPT 長度**：14 頁（Hero 配額 3 頁 = 21%）。

**視覺調性**：沉穩、克制、權威、江湖經驗感、東方人文���——深綠＋琥珀金，宣紙米底，襯線大標題。

**內容邊界**：必講＝三句話重點、三角色定位、節奏公式、五不要／五一定要、現場狀況處理、決策八步、前 24 小時檢核。不講＝互動環節、學員提問環節、講師個人經歷細節（文章裡已有）。禁碰＝簡體字、emoji、條列式口號、任何未在 SOP 原文出現的統計數字。

## ② 頁面佈局骨架

**總頁數 14，分四章**：

- **第一章 · 會議為什麼會壞掉**（P3 扉頁 + P4 內容 + P5 巨型數字）

**目錄↔章節扉頁契約**：目錄 P2 聲明 4 章 → 全篇必須有且僅有 4 個 `type: section` 扉頁 = P3、P6、P10、P13，編號 01–04 連續，標題與目錄逐字一致。

**rhythm 曲線**：
```
P1 peak(封面) → P2 valley(目錄) → P3 transition(扉頁01) → P4 valley → P5 peak(15分鐘)
→ P6 transition(扉頁02) → P7 valley → P8 valley → P9 valley
```
