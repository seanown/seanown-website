## 版本 A｜家訓版（最短、最容易打動人）
> 適合：想讓人有感覺、想被引導去看細節

```
隔了二十四年，我回到祖籍地衢州龍遊。

上一次來，是 2002 年，我捧著曾祖父的骨灰，
坐飛機到澳門，過關進珠海，換綠皮火車到杭州，
再轉大巴、小巴，一路搖到龍遊——送老人家回鄉。

二十四年後，我回來找自己的根。

站在民居苑的碑前，我終於可以說：
我不是發明了一句座右銘，我是找到了一句家訓。

財自道生，利緣義取。
這八個字，龍遊商幫用了幾百年；
我用了大半生，才在龍遊找到它。

我把這趟回家寫下來了：
https://seanown.org/article/quzhou-nankong-returning-home/
```

## 版本 B｜家鄉＋產業版（有信息量、顯得有料）
> 適合：想讓人知道你近來在做什麼、 connections 有交集

```
這趟回去，講百位台商為什麼願意走進衢州。

我的答案很簡單：因為這裡有禮，也有產業；
有鄉愁，也有生意。

融合不是抽象的概念。
鄉愁是：我記得曾祖父的骨灰埋在龍遊的哪座山上。
生意是：龍遊的固態電解質、超聲波機床、19 支基金，
正等著兩岸的資本與人才。

當一個人的鄉愁與一座城的產業疊在一起，
融合就不再是口號，而是腳下的路。

另外想寫一句給在座的朋友：
「我不是發明了一句座右銘，我是找到了一句家訓。」

全文在這裡：
https://seanown.org/article/quzhou-nankong-returning-home/
```

## 版本 C｜敘事版（畫面感強、適合慢慢讀的朋友）
> 適合：朋友偏文青/愛好歷史、會把 link 點開

```
台商朋友需要兩個故事。

大故事，是中國在全世界未來的發展；
小故事，是台商在大陸的機遇。

這是周錫瑋董事長在衢州開場講的話。
那天下午，他講產能過剩、講人才與晶片、講稀土、講 EUV 光刻機。
但我記得最久的，是另一句。

我這半生聽過太多關於「快」的教訓：
快錢、風口、流量、槓桿。
二十多年做企業，我越來越相信一件事——長期者贏。

財自道生，利緣義取。

龍遊商幫在明清十大商幫裡佔一席之地，
靠的不是碼頭，是文化。

我把這趟回家寫下來了，裡面還有八篇致詞稿：
```
