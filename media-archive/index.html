亞洲電子論壇澳門啟幕 共繪AI時代跨境協同新藍圖

【環球新聞報訊】海風送暖，智聚濠江。12月4日，第十六屆亞洲電子論壇（AEF）暨全球智能科技峰會在澳門隆重舉行，來自中國內地、港澳台地區及泰國、越南、日本、烏茲別克斯坦等多個國家和地區的300餘位產業領袖、專家學者齊聚一堂，圍繞「AI重塑生態·協同定義未來」主題共商發展大計，為澳門對接國家「十五五」規劃、打造「數字樞紐」注入強勁動能。

▲中國電子商會會長 王寧

作為亞洲電子產業界規格最高、影響力最廣的年度盛會，本屆論壇由中國電子商會主辦。中國電子商會會長王寧在開幕致辭中指出，亞洲電子論壇歷經二十餘載積澱，已成為推動區域產業協同的重要橋樑，期待藉助澳門的國際化平台，聚焦人工智慧、大數據等前沿領域深化合作，為亞洲電子產業高質量發展注入新動能。

▲亞洲電子論壇秘書長 衛紹邦

亞洲電子論壇秘書長衛紹邦指出，AI驅動全球電子產業深層變革與生態重構，作為產業核心區的亞洲亟需加強對話合作，共迎挑戰、共抓機遇。

▲粵港澳大灣區電子商會會長、澳門龍遊數字服務出海平台聯合創始人 翁振軒

粵港澳大灣區電子商會會長、澳門龍遊數字服務出海平台聯合創始人翁振軒在發言中表示，國家「十五五」規劃明確賦予澳門充分發揮「一國兩制」優勢及自由港、單獨關稅區特色，搭建起跨地域、多層次的產業交流平台「數字樞紐」核心定位，為本地電子產業與AI技術融合發展提供了重大機遇。他介紹，商會孵化的澳門龍遊數字服務出海平台依托澳台雙服務器與雙算力中心，打通跨境數據流通壁壘，作為台灣地區少數獲Facebook數據API授權的企業，六年來已助力近百家企業海外曝光率提升330%、轉化率增長42%。其AI賦能服務可支持80個語種本地化內容生成，上千個AI賬號24小時自動互動，轉化率最高提升80%，為企業合規出海提供高效解決方案。翁振軒倡議，以澳台為「數字樞紐」共建AI跨境服務生態，讓澳門成為中國數字服務出海的「自由港」。

▲中國電子信息產業指數發布暨數據研究院成立啟動儀式

論壇期間，中國電子信息產業指數發布暨數據研究院成立啟動儀式同步舉行，該指數體系將為產業發展提供科學量化依據，標誌著行業評估邁入精細化階段。在主題分享環節，菲律賓、烏茲別克斯坦等國產業代表紛紛推介本地優勢資源，表達與大灣區及澳門企業深化供應鏈合作、技術研發的強烈意願；英偉達、飛書、兄弟（中國）等企業負責人圍繞物理AI、協同創新、生態構建等話題分享前沿觀點，為跨境產業合作提供新思路。

▲圓桌對話

圓桌對話環節，嘉賓們就產業鏈韌性、算力成本、技術轉化等議題展開熱烈討論，多元觀點碰撞凸顯協同創新的重要性。當晚舉辦的「2025亞洲電子信息產業產品創新獎」頒獎盛典上，聯想ThinkBook Plus卷軸屏等10款產品獲「金鼎獎」，澳門參展企業的電子燃香機等20款產品獲「入圍獎」，彰顯亞洲電子產業的創新活力。其中，凌度智能「高空幕牆清洗機器人」憑藉技術突破，有效解決城市高空清潔高危痛點，成為科技賦能民生的生動範例。

▲嘉賓合照

本屆論壇的成功舉辦，不僅集中展現了人工智慧時代的產業創新成果，更凸顯了澳門在鏈接粵港澳大灣區與亞洲各國資源中的核心樞紐作用。正如粵港澳大灣區電子商會會長翁振軒所言，澳門正以更加開放的姿態，整合兩岸暨港澳人才技術優勢，深化與國際市場的對接合作，在國家發展大局中書寫「科技賦能、協同共贏」的澳門篇章。

亚洲电子论坛澳门启航 澳门龙游携澳台双算力 开创AI跨境合作新格局

来源:粵港澳大湾区电子商会

|

|

|

|

本报讯海风送暖，智聚濠江。 12月4日，第十六届亚洲电子论坛（AEF）暨全球智能科技峰会在澳门隆重举行，来自中国内地、港澳台地区及泰国、越南、日本、乌兹别克斯坦等多个国家和地区的300余位产业领袖、专家学者齐聚一堂，围绕「AI重塑生态·协同定义未来——澳台双服务器双算力中心驱动跨境创新」主题共商发展大计，为澳门对接国家「十五五」规划、打造「数字枢纽」注入强劲动能。

作为亚洲电子产业界规格最高、影响力最广的年度盛会，本届论坛由中国电子商会主办，充分发挥澳门「一国两制」优势，搭建起跨地域、多层次的产业交流平台。 中国电子商会会长王宁在开幕致辞中指出，亚洲电子论坛历经二十余载积淀，已成为推动区域产业协同的重要桥梁，期待借助澳门的国际化平台，聚焦人工智慧、大数据等前沿领域深化合作，尤其发挥跨境技术基建优势，为亚洲电子产业高质量发展注入新动能。

粤港澳大湾区电子商会会长、澳门台商监事长、澳门龙游数字服务出海平台联合创始人翁振轩在发言中表示，国家「十五五」规划明确赋予澳门一中心一平台ㄧ基地深化任务，及自由港、单独关税区特色，为澳门成为「数字枢纽」核心定位，为本地电子产业与国内AI技术融合出海发展提供了重大机遇。

他重点介绍，龙游平台作为破解跨境网络壁垒的实践样本，依托独特的澳台双服务器与双算力中心架构，打通了跨境数据流通与网络访问的关键堵点；作为台湾地区少数获Facebook数据API授权的企业，平台六年来已助力近百家企业海外曝光率提升330%、转化率增长42%，其AI赋能服务可支持80个语种本地化内容生成，上千个AI账号24小时自动互动，转化率最高提升80%，为企业合规出海提供了高效解决方案。 翁振轩倡议，以澳台双服务器双算力中心为技术支撑，以龙游平台为实践载体，共建AI跨境服务生态，让澳门成为中国数字服务出海的「自由港」。

论坛期间，中国电子信息产业指数发布暨数据研究院成立启动仪式同步举行，该指数体系将为产业发展提供科学量化依据，标志着行业评估迈入精细化阶段。 在主题分享环节，菲律宾、乌兹别克斯坦等国产业代表纷纷推介本地优势资源，表达与大湾区及澳门企业深化供应链合作、技术研发的强烈意愿；英伟达、飞书、兄弟（中国）等企业负责人围绕物理AI、协同创新、生态构建等话题分享前沿观点，其中跨境网络与数据流通技术创新成为讨论热点，为产业合作提供新思路。 圆桌对话环节，嘉宾们就产业链韧性、算力成本、技术转化等议题展开热烈讨论，多元观点碰撞凸显协同创新的重要性。

当晚举办的「2025亚洲电子信息产业产品创新奖」颁奖盛典上，联想ThinkBook Plus卷轴屏等10款产品获「金鼎奖」，澳门参展企业的电子燃香机等20款产品获「入围奖」，彰显亚洲电子产业的创新活力。 其中，凌度智能「高空幕墙清洗机器人」凭借技术突破，有效解决城市高空清洁高危痛点，成为科技赋能民生的生动范例。

本届论坛的成功举办，不仅集中展现了人工智慧时代的产业创新成果，更凸显了澳门在链接粤港澳大湾区与亚洲各国资源中的核心枢纽作用，而澳台双服务器双算力中心与龙游平台的技术实践，更为跨境数字经济合作提供了可借鉴的「澳门方案」。 正如亚洲电子论坛秘书长卫绍邦所言，澳门正以更加开放的姿态，整合两岸暨港澳人才技术优势，深化与国际市场的对接合作，在国家发展大局中书写「科技赋能、协同共赢」的澳门篇章。

亞洲電子論壇共商AI發展

【本報消息】由中國電子商會主辦的第十六屆亞洲電子論壇暨全球智能科技峰會近日在本澳舉行，來自海峽兩岸暨港澳地區及泰國、越南等多國及地區逾三百位產業領袖、專家學者參加，以“AI重塑生態 · 協同定義未來”為主題共商發展，為澳門對接國家“十五五”規劃、打造“數字樞紐”注入動能。

本屆論壇於本月四日下午二時半假雅辰酒店三樓宴會廳舉行，依托澳門“一國兩制”及自由港優勢搭建跨境交流平台。中國電子商會會長王寧致詞稱，論壇已成為區域產業協同重要橋樑，期待以澳門為紐帶，深化AI、大數據領域跨境合作，助力亞洲電子產業高質量發展。

粵港澳大灣區電子商會會長、澳門龍遊數字服務出海平台聯合創始人翁振軒介紹，龍遊平台憑藉獨特的澳台雙服務器與雙算力中心架構，打通跨境數據流通堵點。作為台灣地區三家獲得臉書數據API授權的企業之一，為企業合規出海提供高效解決方案。倡議未來以雙算力中心為支撐，共建AI跨境服務生態，讓澳門成為中國數字服務出海“自由港”。

論壇期間，中國電子信息產業指數發佈暨數據研究院成立儀式同步舉行，菲律賓、烏茲別克斯坦等國代表表達與灣區尤其澳門企業合作意願，英偉達、飛書等企業圍繞跨境數據流通等熱點分享觀點。當晚頒獎盛典上，聯想ThinkBook Plus卷軸屏等三十款產品分獲“金鼎獎”及“入圍獎”。

澳台青年首簽跨境合作項目 助力推動數字服務走向全球

全文存檔 733 字・附件 4 個 ・原文連結 ↗

展開全文
【特訊】2025澳粵港台青年企業家峰會日前在澳門舉行，期間首個澳門與台灣兩地青年協會合作項目正式簽約落地，標誌兩岸暨港澳青年跨境合作邁入實質性階段。此次合作因活動搭建的交流平台而促成，粵港澳大灣區電子商會會長、龍遊數字服務出海平台聯合創始人翁振軒表示，期望以澳門為跳板，深度對接台灣資源，推動中國數字服務走向全球。

翁振軒表示，國家「十五五」規劃明確澳門「數字樞紐」定位，支持其發揮自由港、單獨關稅區優勢，而澳門與台灣的合作潛力，正成為AI時代跨境產業破局的關鍵。恰逢粵港澳大灣區電子商會完成換屆準備，新一屆理事會將聚焦電子產業與AI技術融合，進一步聯動兩岸暨港澳與亞洲資源，搭建高質量跨境合作橋樑。

作為商會重點孵化的實踐平台，龍遊數字服務出海平台依托澳台雙服務器與雙算力中心架構，順利打通跨境數據流通壁壘。作為台灣地區僅3家獲Facebook數據API授權的企業之一，平台整合多平台出海服務包，六年來已助力近百家企業實現海外曝光率提升330%、轉化率增長42%。其核心AI賦能服務可模擬4種性格、1000種職業屬性，支持80個語種本地化內容生成，上千個AI賬號24小時自動互動，年產2億條精準營銷內容，轉化率最高提升80%，並支持按真實成交結果付費的靈活合作模式。

翁振軒介紹，此次澳台合作項目將重點推進兩大方向：一是以澳台為「數字樞紐」共建AI跨境服務生態，所有境外數據100%合規存儲於澳門，確保符合當地個資法要求；二是以雙算力中心為紐帶，推動兩岸暨大灣區AI技術協同創新，助力澳門打造中國數字服務出海「自由港」。他強調，將秉持開放共贏理念，整合兩岸暨港澳人才技術優勢，沿著先賢足跡，讓中國優質AI數字服務從澳門再啟航，聯接歐亞市場共啟產業出海新紀元。
